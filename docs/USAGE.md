# 使用与配置指南

[返回首页](../README.md) · [工程架构](ARCHITECTURE.md) · [开发与构建](DEVELOPMENT.md)

## 1. 首次启动

1. 获取与你的平台、架构匹配的可信构建，或按开发指南自行构建。
2. 准备可用的 Pi CLI；基础 macOS 配置没有捆绑 Pi/Node。Windows 若有完整固定运行时则可优先使用，但当前仓库交付脚本只产生源码包。
3. 按 Pi 支持的认证方式登录，或在模型设置中配置模型服务。easy_pi 本身不提供免费模型额度。
4. 选择项目工作区。默认工作区可能是用户主目录；使用前确认界面显示的路径，避免无意把无关个人文件作为上下文。
5. 确认 Pi 和图形桥接连接，再使用图形输入栏、角色库与市场。

遇到启动失败时先查看诊断和运行时路径，不要通过删除整个 Pi 配置目录来“重置”。

## 2. 图形输入、终端与布局

### 图形输入与真实 TUI

- 图形输入栏通过本地桥接调用 Pi 的真实编辑器/上下文接口，不是向另一个独立 Agent 发送请求。
- TUI 键盘、选择器和终端输出仍然保留；某些命令需要在终端选择器中完成。
- 图形普通消息入口不接受以 `!` 或 `/` 开头的内容；Pi 指令走单独指令入口，shell 输入留在原生 TUI。
- 原生编辑器已有未处理草稿或弹窗时，图形提交可能被拒绝以避免覆盖；先处理终端中的内容。
- 提交失败时先看错误与连接状态，不要反复发送同一任务。

### 常规布局与壁纸布局

两种布局共用同一个终端与 Pi 进程，不是两套独立会话。支持外观、字体、终端渲染、壁纸与音效设置；WebGL 可关闭，存在非加速路径，不保证所有显卡环境都使用 WebGL。自定义壁纸保存在 WebView 的 IndexedDB 中。

## 3. 模型与供应商

模型面板用于配置管理：列出、选择、添加/编辑、批量选择/删除，以及恢复已移除模型。它不会下载模型权重、启动本地推理服务或替你验证供应商连通性。

### 添加或编辑模型

1. 填写供应商、模型 ID、显示名称、API 协议和 Base URL。模型 ID 与 API 类型必须与服务端匹配。
2. 按需填写 API Key；同供应商多个模型可能共享该 Key。
3. 保存后按界面提示执行 `/reload` 或重启 Pi，再确认模型选择和实际请求。

编辑已有模型时，界面只获取是否存在密钥的标记，不回显现存密钥；**密钥留空表示保留，不是删除**。更换供应商共享密钥会影响使用它的其他模型。模型列表根据本地目录/配置合并，显示某模型不代表已对其完成在线鉴权。

### 批量删除与恢复

批量操作需要用户确认。删除状态与恢复信息记录在 GUI 模型状态文件中；代码在写入时包含配置快照检查和失败回滚。它不是完整配置备份工具，操作前仍建议自行备份重要配置，尤其是供应商与认证设置。

## 4. 角色、人设、本地记忆与 Agent 库

### 人设与 Agent 的区别

- 人设编辑对应 `APPEND_SYSTEM.md`；保存空文本会移除此文件。
- 本地 Agent 是角色 Markdown/纯文本定义；同一时刻只有一个全局激活角色。角色在任务开始时附加到 Pi 系统提示中，不会启动独立子 Agent。
- 本地库记录 Agent 与记忆笔记，位置为 `~/.pi/agent/gui-library/library.json`。

当前记忆注入选择最近 8 条笔记，每条至多 1000 字符，合计提示块约 9000 字符；Agent 定义注入也有截断上限。不要把它当作无限知识库或跨机器同步服务。

### 模型可调用的两个库工具

| 工具 | 允许的动作 |
| --- | --- |
| `gui_memory` | 列出、读取和保存本地记忆笔记 |
| `gui_agent_library` | 列出、读取和下载文本 Agent 定义 |

“记忆”和“自主下载”设置当前默认开启；不希望模型使用时，在本地库设置中关闭。库工具不能修改授权设置、激活角色、删除记录或任意编辑 Agent 定义。**这些限制只覆盖库工具本身，不代表 Pi 的其他文件/命令工具被整体禁用。**

## 5. 纯文本 Agent 市场

市场内置 8 个角色模板：代码审查、故障排查、测试、文档、架构、发布、数据分析与任务规划。目录内容无需联网获取，但市场/本地库操作仍依赖运行中的 Pi 和已连接桥接。

推荐流程：**搜索/分类 → 预览全文 → 勾选确认 → 导入本地库 → 按需设为当前 Agent**。导入不会自动启用，不会覆盖用户已有不同文本后再偷偷切换。

### GitHub 单文件预览

支持公开 GitHub 的具体 `.md` / `.txt` 文件：

- HTTPS `github.com` 的具体 blob/raw 文件，或 `raw.githubusercontent.com` 原始文件。
- 不接受凭据、额外端口、query/hash，不跟随重定向。
- 限制 UTF-8 文本、最多 256 KiB、12 秒获取超时，并检查控制字符。
- 导入前需全文预览与明确同意；预览有有效期和内容哈希检查。

这里不是全网搜索引擎，也不是 MCP、DSH 插件、主题或二进制代码商店。外部文本始终应视为不可信内容：不能把其中的“系统指令”当作用户授权。详情见 [市场来源与兼容范围](../市场来源与兼容范围.md)。

### 与“导入插件”的区别

应用另外有调用 `pi install <source>` 的插件导入入口。这会交由 Pi 解释 npm/git/URL/本地来源，可能联网并引入可执行代码，**不享有纯文本市场的来源白名单、预览同意和纯文本边界**。只安装自己核实过的来源，完成后按提示 `/reload` 或重启。

## 6. 工作区、文件和 Git

### 文件操作

- 支持文件树、按路径名称搜索、现存 UTF-8 文本文件读取/编辑/保存以及把文件加入输入上下文。
- 当前编辑器限制为不超过 512 KiB、无 NUL 的 UTF-8 文件；不是二进制编辑器，也没有完整 IDE 的新建/删除/重构能力。
- 保存时比较 revision，外部已修改时拒绝覆盖，并保留原文件权限。
- 路径搜索不是全文搜索；结果最多 100 条，候选扫描上限 20000。
- GUI 文件 API 拒绝绝对路径/父级越界和越出工作区的符号链接。这个边界不限制 Pi 的一般工具执行。

### Git 审阅

可查看未暂存/已暂存变更、分支三点比较与逐文件差异，并执行暂存/取消暂存。需要系统 Git；当前不是完整的 commit / push / merge 客户端。大输出受到后端限制。

### 工作区切换

切换前需要处理进行中的任务、原生输入草稿及未保存文件；切换会重启当前 Pi 子进程。这不是并行运行多个工作区/Agent 的调度器。

## 7. 会话和附件

- 会话读取自 `~/.pi/agent/sessions/` 下的 Pi JSONL，支持搜索、恢复及当前/全部工作区过滤。
- 置顶/归档是 WebView 本地展示状态，不会移动或删除原始会话。
- 当前扫描保留至多 150 个近期结果，递归深度有限，单文件读取至多前 16 MiB；未列出不一定代表会话不存在。
- 文件拖入/选择后以本地 `@路径` 加入草稿，等待用户发送；不是上传到 easy_pi 自建的云存储。
- 粘贴图片支持 PNG/JPEG/GIF/WebP，单图至多 8 MiB，每次最多 5 张、草稿最多 20 个附件。缓存写入 Tauri 应用缓存目录。

**Windows 限制：** 当前部分前端附件逻辑只接受 `/` 开头路径，且多处按 `/` 分隔路径；常见盘符/UNC 路径可能被忽略。不要把 Windows 文件附件体验描述成与 macOS 完全一致。原生文件/文件夹选择器目前只提供 macOS/Windows 分支。

## 8. 数据存储位置

`~` 指应用进程的 HOME；Windows 在 HOME 缺失时会用 USERPROFILE 补齐。

| 数据 | 位置或机制 |
| --- | --- |
| 自定义供应商/模型，可能含 API Key | `~/.pi/agent/models.json` |
| 模型目录 | `~/.pi/agent/models-store.json` |
| 认证数据 | `~/.pi/agent/auth.json` |
| Pi 设置及默认模型 | `~/.pi/agent/settings.json` |
| GUI 模型移除/恢复状态 | `~/.pi/agent/gui-models.json` |
| 人设追加提示 | `~/.pi/agent/APPEND_SYSTEM.md` |
| 快捷键覆盖 | `~/.pi/agent/keybindings.json` |
| Pi 会话 | `~/.pi/agent/sessions/` |
| Agent 本地库与记忆 | `~/.pi/agent/gui-library/library.json` |
| 外观、语言、草稿、工作区、置顶/归档展示状态 | WebView `localStorage` |
| 自定义壁纸 | IndexedDB `pi-wallpaper` / `files` |
| 粘贴图片缓存 | Tauri `app_cache_dir()/attachments` |
| 调试日志 | `~/.pi_app_debug.log` |
| 终端纯文本导出 | `~/Downloads/pi-terminal-*.txt` |

导出的是当前终端缓冲区文本，不是完整结构化会话备份。日志没有自动脱敏保证。JSON 配置是本地文件，不是 OS Keychain 加密保险库。卸载前请自行判断需要备份的配置、会话及 WebView 数据，不要将整个配置目录提交到 Git。

## 9. 环境变量与运行时查找

| 变量 | 作用 |
| --- | --- |
| `PI_EXECUTABLE` | 显式指定 Pi 可执行文件的绝对路径；优先于 Windows bundle 和自动搜索 |
| `HOME` / `USERPROFILE` | 用户目录基准；缺少 HOME 时由 USERPROFILE 补齐 |
| `PATH` | 外部工具查找；后端还会补充若干常用本地 bin 路径 |
| `TERM` / `COLORTERM` | 启动 Pi 时设置 `xterm-256color` / `truecolor` |
| `LANG` / `LC_ALL` | 继承语言环境；均缺失时补充 UTF-8 默认值 |
| 供应商环境变量 | 后端处理 `*_API_KEY`、若干供应商前缀和 `PI_*` 等；不是安全隔离保证 |
| `PI_GUI_SOCKET` / `PI_GUI_TOKEN` | 由应用内部生成并注入的桥接参数；无需手工设置，也不应分享 |

Unix 自动搜索包含 `~/.local/bin`、`~/.bun/bin`、`~/.npm-global/bin`、`/opt/homebrew/bin`、`/usr/local/bin` 与 PATH；不会自动遍历所有 NVM 版本或读取交互 shell 配置。

**自定义 Pi 数据目录：** GUI 配置读写与本地库按 HOME 下 `.pi/agent` 定位，并未完整适配 `PI_CODING_AGENT_DIR`。虽然 `PI_*` 可能传递给子进程，不能据此承诺 GUI 与 Pi 自定义目录始终一致。

构建/测试专用的 `PI_WINDOWS_RUNTIME_ARCHIVE` 和 `PI_GUI_SMOKE_*` 见 [开发指南](DEVELOPMENT.md)；不要把它们当作普通用户必填项。

## 10. 常见问题

### Pi CLI was not found

确认 `pi --version` 正常，检查桌面进程继承的环境；必要时用可执行文件绝对路径设置 `PI_EXECUTABLE` 并重新启动。若由 npm shim 启动，也要确认 Node 可被其实际运行环境找到。不要仅提供 npm 包目录或相对路径。

### 模型保存了但列表或请求未变化

按照提示 `/reload` 或重启 Pi；核对供应商名称、模型 ID、协议、Base URL 与认证。列表存在不等于服务可访问；避免在问题反馈中暴露 Key。

### Agent 市场或本地库提示未连接

先确认真实 Pi 进程和桥接状态。内置目录不需要下载，不代表市场 API 在无 Pi 时也可运行。外部 GitHub 预览还需要网络与被接受的文件 URL。

### 文件无法保存或搜索不到

检查是否为工作区内的现存 UTF-8 文本、文件大小是否超限、是否外部改动导致 revision 冲突，以及是否触及搜索结果/扫描上限。Windows 另外注意当前路径兼容限制。

### 导出的日志可以直接公开吗？

不可以默认认为已脱敏。先移除 API Key、认证信息、私有代码、个人路径和对话。安全反馈参见 [SECURITY.md](../SECURITY.md)。
